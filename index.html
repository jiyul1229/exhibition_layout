건물 평면·구조 편집기

사용법: 드래그로 대략 그리거나 아래 좌표·벡터 입력란에서 정확한 수치를 지정할 수 있습니다. 방은 바닥 영역과 네 벽을 만드는 구조물이고, 그림은 벽면에 전시됩니다. 단, 새로 만든 내부 벽을 AI 작품 배치 대상으로 쓰려면 별도의 벽면 연동이 필요합니다. 벽은 시작점+방향 벡터로 지정할 수 있고, 문·창문은 벽에 붙여 배치합니다. 격자 간격은 0.5m입니다.

정확한 좌표·벡터로 만들기 (단위: m)

원점 A=(X, Z)를 입력하고 벡터 v=(ΔX, ΔZ)를 더해 끝점 B=A+v를 계산합니다. 방은 A와 B가 대각선의 두 모서리인 직사각형(축 정렬)으로 생성되고, 벽은 A에서 B까지 선분으로 생성됩니다. 좌표 원점 (0,0)은 전시장 중심이며, 평면도에서 +X는 오른쪽, +Z는 아래쪽입니다. 드래그 조작도 계속 사용할 수 있습니다.

평면도 좌표는 미터 단위로 저장됩니다. 방은 내부 구획 벽 4개를 생성하고, 문·창문은 벽에 실제 개구부를 만듭니다. 독립 기둥은 바닥의 지정 위치에 3D로 표시됩니다.
평면도에서 방·벽·문·창문·기둥을 선택하면 편집 항목이 여기에 표시됩니다.

AI 자동 배치 시스템

전시실 바닥과 경계 벽, 입구 개구부만 표시합니다. 복도·창고·화장실 등은 제외되며, AI 배치안은 현재 선택한 전시실의 실제 벽 선분과 입구 위치를 기준으로 비교합니다.

업로드 이미지 분석 결과 또는 예시 작품으로 배치 후보를 탐색합니다. 작품 중심을 벽 높이의 중간보다 조금 위(55%)에 거는 것을 기본으로 하며, 큰 액자는 나무 벽 장식에 겹치지 않도록 높이를 자동 조절합니다. 문·벽 크기·간격도 검증합니다.

1. 실제 작품 이미지 불러오기 · 분석

예시 작품 6개로 시작합니다. 이미지를 고르면 예시 작품 대신 들어가고, 다시 고르면 목록에 추가됩니다(최대 40개). 작품의 실제 cm 크기는 직접 입력해야 합니다.

CLIP 모델은 처음 사용할 때 인터넷에서 내려받아 이 기기에서 분석합니다. 작품별 이미지 임베딩의 코사인 유사도로 섹션을 자동으로 나누고, 섹션은 목록에서 직접 바꿀 수 있습니다. 주제 라벨은 섹션 이름에 쓰입니다. 주제 분류의 상대 점수가 낮거나 2위와 비슷하면 검토 필요로 표시합니다. 수동으로 수정한 값은 재분석해도 유지됩니다.

2. 자동 배치 최적화

전시장 평면도

평면도는 전달받은 이미지 도면을 추적해 만든 참고용 구조입니다. 일부 치수와 층고는 추정값입니다.

선택한 전시장에 구조물 추가

창문·벽기둥·낮은 보·독립 기둥을 실제 선택한 맵에 추가합니다. 벽 오브젝트는 벽 시작점에서 떨어진 거리(m)를 입력합니다. 추가한 구조물은 배치 최적화의 장애물로 반영됩니다.
